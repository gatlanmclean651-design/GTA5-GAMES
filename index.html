Putting your own games here

  1. Open the repository on GitHub and upload the game's web files into a new folder inside games/.
  2. Open games.json and add an entry with the game's name and its main HTML file.
  3. Commit the changes. If GitHub Pages is enabled, the game appears on your shelf.

Only games made for browsers (HTML, CSS and JavaScript, or a browser build from a game engine) can run here. Desktop game files such as .exe files cannot run directly in a webpage.
